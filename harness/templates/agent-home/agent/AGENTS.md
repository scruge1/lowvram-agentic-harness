# Agent profile

Read `{{HOME}}/AGENTS.md`, `{{HOME}}/context/startup-index.md` and
`{{HOME}}/context/current.md`.
Use the nearest project's instructions when entering a project. Do not treat
the agent home's board as the board for an unrelated project.

Use `project_admit` before project execution. Discover actual native tools,
query relevant system capabilities, memory and project knowledge. Select the
existing ready task. An external planning adviser is optional.

Use `workflow_step` for declared file outputs with a relevant verifier.
The verifier must reject missing output in its empty-directory negative control.
Read the complete saved failure before recovery. A timeout and printed process
ID do not prove a job is still running. Preserve uncertain effects for review.

Startup and config files enforce only the installed controls. Run doctor and
the native host acceptance checks before claiming enforcement on a new host.
